# 5.15 压缩作品集第一轮筛选

## 结果

- 原始素材：115 张，不改动。
- 网站首批推荐：59 张。
- 首页精选：8 张。
- 其余 56 张作为备选，先不导入。

## 筛选标准

1. 先看首屏主体和信息层级是否清楚。
2. 同系列保留最能说明能力的几张，不用数量制造重复。
3. 保留安静、商业、信息密度高和系列化几种不同面貌。
4. 有明显文字或商品参数风险的图，即使视觉完成度高，也需要上线前复核。
5. 首页只放 8 张，让视觉跨度大于数量。

## 分类判断

- **商业设计合集**：保留旅游、商业地产、活动、电商横幅与品牌延展，控制同风格横幅数量。
- **电商视觉设计**：按肉肠、坚果果干、健步鞋、户外服装四组展示，每组保留首图、卖点图和信息图。
- **节日热点**：二十四节气是完整系列，首批只保留跨季节的代表图；另加端午、中秋、国庆等不同构图。
- **自媒体封面设计**：保留人物种草、产品、留学旅行、个人转型和知识类封面，减少同类副业选题的重复。

## 首页 8 张

`CM02` `CM09` `CM13` `CM14` `EC01` `EC19` `FD03` `SC11`

## 上线前必须由作者确认

- 品牌名和客户项目是否允许公开。
- 电商参数、价格、产品成分和功效表述是否准确。
- 自媒体封面中的标题和信息是否需要修正。
- 这批图的文件名显示为 ChatGPT Image，网站上建议标为“AI 辅助视觉”或“混合制作”，不归入“AI 前”作品。
