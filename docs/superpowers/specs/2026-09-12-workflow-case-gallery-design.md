# 工作流案例图集设计

## 目标

把 `G:\个人网站开发\图片` 中的四张公众号工作流案例图加入“公众号快速创作”详情页，让访问者快速理解工作流的结构、顺序、安全边界与交付物。

## 内容与顺序

四张图片按照文件编号展示：

1. 内容生产系统总览：从想法到成品。
2. 六步工作顺序：输入、判断、创作、视觉、检查、交付。
3. 信息安全原则：展示方法、节点和交付物，隐藏账号、路径、来源与数据。
4. 可复用交付物：内容成品、视觉版本和流程模板。

## 页面结构

- 案例图集位于工作流正文之后、相邻工作流导航之前。
- 区域标题使用“案例图解”，英文辅助标签使用 `CASE STUDY / WORKFLOW`。
- 桌面端两列排列，四张图形成紧凑的 2×2 网格。
- 手机端切换为单列，保持原始顺序。
- 每张图片下方显示简短说明，不额外添加长篇解释。

## 数据结构

- 在工作流内容模型中加入可选的 `gallery` 数组。
- 每项包含 `src`、`alt`、`width`、`height` 和可选 `caption`。
- 没有 `gallery` 的其他工作流不显示空区域。
- 后续新增案例只需复制图片并填写内容数据，无须修改页面组件。

## 图片处理

- 将原始 PNG 复制到 `public/images/workbenches/wechat-writing/`，使用稳定英文文件名。
- 保留 1448×1086 原图，不裁切、不拉伸、不进行有损压缩。
- 页面按图片自身 4:3 比例展示，并声明固有尺寸，降低加载时的页面跳动。

## 响应式与验收

- 桌面端显示两列，手机端显示一列。
- 390px 手机宽度下显示一列且无横向滚动。
- 四张图片全部加载，顺序和说明准确。
- 其他四个工作流详情页不出现空的“案例图解”区域。
- Astro 检查、构建、单元测试和 Playwright 全站测试通过。
